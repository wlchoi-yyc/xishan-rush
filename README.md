# 極速西山 · Xishan Rush

《始得西山宴遊記》3D 背誦戰車試玩版。

- 直接開啟 `index.html` 即可在現代瀏覽器試玩；需要網絡載入 Three.js。
- 支援手機觸控左右換線，以及電腦左右方向鍵／A、D。
- 遊戲共 18 道背誦選擇題。
- 初版雷射屬視覺效果，答案按車道位置判定；尚未加入射線命中檢測。

## Firebase Hosting

已提供 `firebase.json`，但仍需要在 Firebase 選定項目並授權執行部署。此儲存庫並未存放 Firebase 登入憑證或項目 ID。

本專案使用簡單靜態部署，Hosting 網站根目錄設為專案根目錄。

## GitHub Pages

目前儲存庫為私人儲存庫。GitHub Pages 的啟用及可見性取決於帳戶方案與儲存庫設定；只推送程式並不會自動開啟 Pages。
